# Quantization

Q5_0 first, then Q4_K_M. After those, compare round-to-nearest, importance-weighted K-quant, and a
GPTQ/AWQ-like pass where a layer fits. The last step is file size, resident GPU memory, and warm
latency against Q8_0.

Q5_0 is 32 weights, an f16 scale, and five-bit codes: 22 bytes in the file. On the GPU the codes
are repacked into weight order, 24 bytes per block, plus the f16 scale, and the GEMM, gemv, and
embed dequantize them in the kernel. The CPU decoder stores each code as `code - 16` with that
scale and uses the Q8 tile. The Neural Engine dequantizes Q5_0 to F16 at load. GigaAM's CPU
decoder still expands its weights at load, as it does for Q8_0.
